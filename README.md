# AI-конструктор резюме и портфолио

Лендинг-презентация → регистрация или вход → личный редактор → помощь Gemini → PDF. Сохранены семь шаблонов, палитры, светлая и тёмная темы, фотография с обрезкой и два формата PDF. Портфолио добавляется ссылками на работы.

Главная использует самостоятельный редакционный дизайн: графитовая палитра, Manrope, три фотографии, созданные ИИ, светлая коллекция шаблонов и сдержанный пример разбора резюме и финальный блок с большой фотографией. Четыре превью резюме на лендинге строятся тем же `renderResume`, что и в редакторе; это заполненные документы на демонстрационных данных. Из галереи и блока портфолио сохраняется выбранный следующий шаг после входа. Статистика на странице описывает существующие функции, отзывы и число пользователей не выдумываются.

## Запуск

Нужен Node.js 22.13 или новее с `node:sqlite` (рекомендуется актуальный LTS). Зависимости устанавливать не нужно. В Windows откройте `start.cmd` либо выполните из этой папки:

```sh
npm start
```

Главная страница: http://127.0.0.1:4173. Регистрация: `/auth`, вход: `/auth?mode=login`, редактор: `/editor`. Без сессии редактор перенаправляет на вход.

Главная проверяет действующую сессию через `/api/auth/me`: после входа отображаются ник, меню профиля, настройки и переход в редактор. Гостевые кнопки показываются только гостю. При возвращении на страницу и переключении обратно во вкладку статус обновляется. В `/settings` можно изменить ник (он не меняет имя в резюме), заменить/удалить личный Google API key и выйти.

После выбора шаблона доступны скачивание PDF и «Далее: портфолио и площадки». В отдельной вкладке «Портфолио и отклики» редактируются ссылки на работы из личного черновика и показываются 30 сайтов вакансий с поиском и фильтрами по региону/удалённой работе. Строки открывают сайты в новой вкладке; резюме, контакты и API keys автоматически им не передаются. Для загрузки PDF и отклика пользователь входит на выбранную площадку самостоятельно. Каталог — прямые ссылки, не интеграция с кабинетами этих сервисов. «Скачать пример PDF» в галерее экспортирует показанное демонстрационное резюме и не подменяет личный черновик.

После регистрации нажмите «Пример: Андрей Наумов», чтобы загрузить демонстрационное резюме веб-дизайнера из Ташкента. Имя задано пользователем, остальные сведения вымышлены. Это учебный пример, а не проверенные данные человека; контакты и ссылка на портфолио используют example.com. Перед отправкой работодателю замените сведения реальными.

Вкладка «Пример с фото · 7 дизайнов» показывает отдельное заполненное резюме с портретом, созданным ИИ. Шаблоны можно сравнивать на одинаковых данных без изменения личного черновика. «Этот дизайн для моего резюме» меняет только оформление; «Заполнить этим примером» загружает данные и фото с подтверждением замены заполненного черновика. Прямая ссылка после входа: `/editor?view=example`.

Все семь дизайнов имеют отдельную композицию: классика с центрированным именем, «Графит» с тёмной левой колонкой, кремовый редакционный с правой колонкой, синий «Архитектор», зелёное «Портфолио», тёмный «Монолит» и пудровая «Карьера». Предпросмотр, галерея и PDF используют общее описание размещения секций и цветов. После обновления сервер нужно перезапустить и обновить страницу с очисткой кеша, чтобы загрузились новые маршруты и стили.

## Подключение ИИ

1. В редакторе нажмите «Подключить Google API key».
2. Перейдите по ссылке на https://aistudio.google.com/apikey, создайте свой ключ и вставьте его в поле настроек. Не присылайте ключ в чат и не добавляйте его в исходники.
3. Используйте «Сформулировать с ИИ» либо блок «Взгляд со стороны» в конце формы. Перед отправкой пользователь подтверждает передачу данных Google.

Для каждого аккаунта используется только сохранённый им ключ. Общего ключа сервиса и резервного чужого ключа нет. Проверка формата при сохранении не означает, что Google принял ключ: доступ и квота проверяются первым запросом. Доступность и расходы зависят от Google-проекта пользователя.

ИИ оценивает пять разделов: должность, «О себе», опыт, навыки и образование. Красный — слабое место, жёлтый — хорошо, зелёный — отлично. В карточках есть объяснение, рекомендация и переход к полю. Можно задать вопрос о текущем резюме. Готовые формулировки появляются рядом с полями: их можно принять, отредактировать или отклонить. После изменения исходных данных анализ помечается устаревшим. Оценка качества текста субъективна и не предсказывает найм.

В Google отправляются должность, навыки, опыт и образование; для анализа также текст «О себе» и вопрос. Имя, фото, дата рождения, город и контактные поля исключены. Личные сведения, самостоятельно внесённые в свободный текст, всё же попадут к провайдеру. Инструкции запрещают ИИ придумывать работодателей, даты, навыки и результаты; пользователь проверяет каждую предложенную правку.

## Аккаунты и данные

- Аккаунты и сессии хранятся в `data/accounts.sqlite`. Пароли хешируются scrypt с индивидуальной случайной солью. В базе хранится хеш сессионного токена; cookie — HttpOnly и SameSite=Strict, срок сессии семь дней. Выход отзывает текущую сессию.
- API key шифруется AES-256-GCM с привязкой к идентификатору владельца. Ключ шифрования — `data/encryption.key`; он создаётся автоматически. API не возвращает сохранённые ключи, в интерфейсе доступна только замена или удаление. Доступ другого аккаунта к ключу проверяется сервером. Администратор с доступом к серверным файлам технически может расшифровать ключи: защита аккаунтов не заменяет защиту самого сервера.
- Ключи не записываются в localStorage, IndexedDB, исходники или журналы. Директория `data/` исключена из Git и недоступна через статические маршруты. Защита от межсайтовых запросов, лимиты запросов и проверка ответа Gemini выполняются на сервере.
- Черновик с фотографией хранится локально в IndexedDB, отдельно для каждого аккаунта. Он не синхронизируется между устройствами. Старый анонимный черновик остаётся в прежней базе браузера и автоматически в аккаунт не переносится. Локальные черновики не шифруются: на общем устройстве нужен отдельный профиль браузера.
- Регистрация по email и паролю локальная: подтверждение email и восстановление пароля пока не реализованы.

## Настройка сервера

Необязательно скопируйте `.env.example` в `.env`. `GEMINI_MODEL` задаёт модель (по умолчанию `gemini-2.5-flash`), `PORT` — порт, `HOST` — интерфейс. Общий Google/OpenAI API key не требуется.

Для размещения нужен сервер Node.js с постоянным диском под SQLite и ключ шифрования. Укажите `DATA_DIR` абсолютным путём вне публичной директории. Храните резервные копии базы и `encryption.key` вместе в защищённом хранилище: без ключа старые API keys не восстановить. Ограничьте доступ к этим файлам учётной записью приложения. Для HTTPS установите `COOKIE_SECURE=true`; TLS завершайте на доверенном reverse proxy. Текущий сервер рассчитан на один экземпляр; обычные эфемерные serverless-инстансы не подходят для локальной базы. Публичный деплой в рамках этой правки не выполнялся.

PDF создаётся в браузере с системным шрифтом Arial, DejaVu Sans или Liberation Sans. При необходимости задайте `PDF_FONT` путём к TTF с кириллицей.

## Проверки

```sh
npm test
```

Проверяются валидация и исключение личных полей из ИИ-запроса, закрытый редактор, регистрация/вход/выход, отзыв сессии, изоляция двух аккаунтов и их ключей, зашифрованные записи, межсайтовые запросы, проверка ответа Gemini, ошибки квоты и все 14 сочетаний шаблонов с форматами PDF. HTTP-обработчик запускается напрямую без сетевого сокета; Gemini заменяется контролируемым ответом только внутри теста. Реальная работа Google проверяется отдельно личным ключом в интерфейсе.



## Blue theme and Google connection check

Home, authentication, settings and editor share a blue palette. First visit defaults to light; the theme choice persists and synchronizes across tabs. The hero uses blue-profile-hero.jpg.

Keys are opaque values without a mandatory AIza prefix. The connection check requests metadata of the configured Google model without sending resume data. Model access and generation quota are separate. Keys remain encrypted per account. Connection tests use artificial keys and mocked Google responses.
