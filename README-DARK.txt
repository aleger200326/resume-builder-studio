ТЁМНАЯ ВЕРСИЯ САЙТА

Главная восстановлена из сохранённого оформления с крупным заголовком и наклонённым макетом резюме. Вход, редактор, PDF и проверка Google API key взяты из текущего проекта. Это восстановленная копия оформления, а не полный исторический снимок.

Запуск: дважды нажмите start.cmd (требуется Node.js 22.13+).
Адрес: http://127.0.0.1:4174/

База аккаунтов и личные API-ключи в копию не включены. Создайте отдельный аккаунт при первом запуске. Текущая голубая версия находится в соседней папке resume-builder и не изменена.
